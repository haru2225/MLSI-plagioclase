# Derived / selected CIFs

These files are supplemental; the source CIFs used by `tools/build_structures.py` are in `../`.

- `labradorite_An59Ab40_COD2108244.cif` is a copy of COD 2108244 (the measured average structure, 100 K). It has average/disordered sites and is not an ordered atomistic model.
- Lingunite (NaAlSi3O8 hollandite) is built in `tools/build_structures.py` from the K-hollandite coordinates in COD 9001521 with K replaced by Na; Al/Si are disordered 1:3 on the octahedral site. It is not a measured Na-lingunite structure.
